Windows에서 독립적으로 실행되는 영어 영상 전사·번역·Notion 저장용 GUI 프로그램을 만들어 주세요.

이 프로그램의 목적은 사용자가 로컬 영상 파일 또는 YouTube 영상 URL을 입력하면, 내 Windows PC의 GPU를 이용해 로컬 Whisper로 영어 음성을 전사하고, OpenAI GPT API를 이용해 자연스러운 한국어 번역을 생성한 뒤, 정해진 전사문 형식으로 조합하여 내 Notion의 특정 페이지 아래에 자동 저장하는 것입니다.

완성된 프로그램은 Kiro 없이 독립적으로 사용할 수 있어야 하며, 최종적으로 일반적인 Windows .exe 프로그램으로 실행할 수 있어야 합니다.


[전체 작업 흐름]

다음 파이프라인을 자동으로 수행하도록 구현해 주세요.

영상 입력
→ 오디오 추출
→ 로컬 faster-whisper로 영어 전사
→ 타임스탬프와 영어 문장 구조 보존
→ 여러 영어 문장을 적절한 묶음으로 GPT API에 전달
→ 문맥을 고려한 자연스러운 한국어 번역 생성
→ 아래의 전사문 규칙에 맞게 영어 원문과 한국어 번역 결합
→ Notion API를 통해 지정된 "영어듣기" 페이지 바로 아래에 새 하위 페이지 생성
→ 작업 성공 후 불필요한 임시 파일 삭제


[1. 입력 방식]

두 가지 입력 방식을 지원해 주세요.

1) 로컬 영상 파일
- MP4
- MKV
- MOV
- WEBM

파일 선택 UI를 제공합니다.

Notion에 생성되는 페이지 제목은 영상 파일의 확장자를 제거한 파일명을 그대로 사용합니다.

예:
How Wasianiversion hit rank 1.mp4

→

How Wasianiversion hit rank 1


2) YouTube URL

사용자가 YouTube URL을 붙여넣을 수 있도록 합니다.

yt-dlp와 같이 적절하고 유지보수되는 도구를 사용하여 Whisper 전사에 필요한 오디오를 임시로 확보합니다.

YouTube 입력의 경우 Notion 페이지 제목은 해당 YouTube 영상의 제목을 자동으로 가져와 사용합니다.

전사 및 최종 Notion 저장이 성공하면 다운로드한 임시 오디오/영상 파일은 자동으로 삭제합니다.

YouTube 다운로드가 불가능한 영상은 프로그램이 멈추거나 비정상 종료되지 않도록 하고, 사용자에게 이해하기 쉬운 오류 메시지를 표시합니다.


[2. Whisper 전사]

음성 인식은 클라우드 API가 아니라 사용자 PC에서 완전히 로컬로 실행합니다.

기본 구성:

- faster-whisper
- Whisper large-v3-turbo
- language = English
- NVIDIA CUDA GPU acceleration

사용자 PC 사양:

CPU: AMD Ryzen 5 5600
GPU: NVIDIA GeForce RTX 4060 8GB
RAM: 16GB
OS: Windows

이 환경에서 RTX 4060을 정상적으로 활용하도록 구성해 주세요.

GPU 가속을 사용할 수 없는 경우 조용히 CPU로 전환하지 말고, 사용자가 현재 CUDA/GPU가 사용되지 않는다는 사실을 알 수 있도록 명확하게 표시해 주세요.

Whisper의 영어 전사 결과는 후속 단계에서 임의로 교정하거나 다시 작성하지 않습니다.

Whisper가 잘못 인식했다고 판단되는 문장이 있더라도 GPT가 영어 원문을 수정해서는 안 됩니다.

즉:

Whisper English output = 최종 전사문의 English source of truth

입니다.


[3. 전사문 형식]

최종 전사문은 다음 규칙을 반드시 따릅니다.

기본 구조:

English sentence.
자연스러운 한국어 번역.

English sentence.
자연스러운 한국어 번역.

English sentence.
자연스러운 한국어 번역.


각 영어 발화/문장을 먼저 배치하고, 바로 다음 줄에 해당 문장의 한국어 번역을 배치합니다.

영어 원문과 한국어 번역은 가능한 한 1:1로 대응되어야 합니다.

영어 원문은 Whisper 출력에서 가져오며 번역 과정에서 수정하지 않습니다.

짧은 문장이나 반복되는 발화라고 해서 임의로 삭제하거나 합치지 않습니다.

영상에서 발화된 순서를 그대로 유지합니다.


[4. 2분 단위 타임스탬프]

전사문에는 영상 시간 기준으로 2분마다 다음 형태의 구분선을 삽입합니다.

────────── 2:00 ──────────

────────── 4:00 ──────────

────────── 6:00 ──────────

────────── 8:00 ──────────

이후에도 영상 끝까지 같은 방식으로 계속합니다.

Whisper의 segment timestamp를 이용하여 가능한 한 실제 영상 시간에 정확하게 대응하도록 구현해 주세요.

타임스탬프 때문에 문장 순서가 변경되거나 문장이 누락되어서는 안 됩니다.


[5. GPT 한국어 번역]

한국어 번역은 OpenAI API의 GPT 모델을 사용합니다.

한 문장마다 개별 API 요청을 보내지 마세요.

여러 영어 문장을 적절한 크기의 chunk로 묶어 GPT에 전달하여 앞뒤 문맥을 참고할 수 있도록 합니다.

다만 GPT의 출력은 반드시 각 영어 문장과 1:1 대응되는 한국어 번역으로 반환되도록 구조화해 주세요.

중요한 번역 원칙:

- 영어 원문은 절대 수정하지 않습니다.
- 번역은 단순한 기계적 직역보다 실제 영상의 문맥을 반영한 자연스러운 한국어를 우선합니다.
- 의미를 임의로 추가하거나 요약하지 않습니다.
- 원문의 정보와 뉘앙스를 최대한 유지합니다.
- 고유명사와 전문용어는 필요할 경우 영어 표기를 유지합니다.
- 게임명, 사람 이름, 제품명, 기술용어 등은 부자연스럽게 한국어화하지 않습니다.
- 반복되는 발화나 짧은 문장도 생략하지 않습니다.

GPT가 영어 원문의 오류를 발견하더라도 영어 문장을 교정해서는 안 됩니다.

GPT의 역할은 "영어 전사 교정"이 아니라 "문맥 기반 한국어 번역"입니다.


[6. GPT 모델 설정]

OpenAI API에서 사용할 GPT 모델명을 코드 내부에 고정하지 마세요.

프로그램의 설정에서 모델명을 변경할 수 있도록 구현합니다.

즉 번역 로직과 모델 선택을 분리하여, 나중에 새로운 GPT 모델을 사용하고 싶을 때 프로그램 전체를 수정할 필요 없이 모델 설정만 변경할 수 있어야 합니다.

현재 사용할 기본 모델은 구현 시점에서 OpenAI API에서 사용 가능한 비용/성능 균형이 좋은 모델을 선택하되, 모델명을 쉽게 변경할 수 있는 구조가 더 중요합니다.


[7. 번역 안정성]

긴 영상도 안정적으로 처리할 수 있어야 합니다.

예를 들어 1시간 이상의 영어 영상에서도:

Whisper 전체 전사
→ 적절한 단위로 chunk 분할
→ GPT 번역
→ 결과 재조립

방식으로 처리합니다.

각 chunk에는 문장/segment의 고유 ID를 부여하는 등 안정적인 방법을 사용하여 GPT 번역 결과와 Whisper 원문을 정확히 다시 매칭해 주세요.

GPT 출력 형식 오류로 인해 문장이 누락되거나 순서가 바뀌지 않도록 검증 로직을 구현해 주세요.

번역 결과의 개수와 입력 문장의 개수가 일치하지 않거나 응답 구조가 잘못된 경우 해당 chunk를 자동으로 재시도할 수 있도록 합니다.

이미 정상적으로 번역된 전체 영상을 처음부터 다시 처리할 필요가 없도록, 실패한 단계만 합리적으로 재시도하는 구조를 사용합니다.


[8. Notion 저장]

최종 결과는 Notion API를 사용해 자동 저장합니다.

저장 대상은 현재 사용자가 사용하는 Notion의 "영어듣기" 페이지입니다.

프로그램 설정 과정에서 이 페이지의 고유 Page ID를 지정하고 저장할 수 있도록 합니다.

새로운 영상 하나를 처리할 때마다 "영어듣기" 페이지 바로 아래에 새로운 하위 페이지를 생성합니다.

구조 예:

영어듣기
├─ 기존 영상 전사 페이지
├─ 기존 영상 전사 페이지
└─ 새 영상 제목
   └─ 전체 영어/한국어 전사문

Notion 페이지의 제목:

로컬 영상
→ 확장자를 제거한 파일명

YouTube
→ YouTube 영상 제목

Notion 페이지 본문에는 앞에서 정의한 전사문 형식을 그대로 저장합니다.

Notion API의 block/content 길이 제한 때문에 긴 전사문을 한 번에 저장할 수 없는 경우 자동으로 적절한 크기로 나누어 순서대로 추가해 주세요.

긴 영상에서도 페이지 내용이 중간에 누락되지 않도록 검증합니다.


[9. 로컬 파일 저장 정책]

사용자는 최종 결과를 PC의 TXT 파일 등으로 별도로 보관할 필요가 없습니다.

최종 결과의 영구 저장 위치는 Notion만 사용합니다.

처리 과정에서 필요한:

- 추출 오디오
- YouTube 임시 다운로드
- 임시 Whisper 데이터
- 번역 처리용 임시 데이터

등은 작업 성공 후 자동으로 정리합니다.

단, 처리 중 오류가 발생했을 때 복구나 재시도에 필요한 데이터까지 즉시 삭제하여 전체 작업을 처음부터 다시 해야 하는 구조는 피해주세요.

성공적으로 Notion 저장과 검증까지 완료된 후 최종 정리를 수행합니다.


[10. 인증정보]

OpenAI API Key와 Notion Integration Token을 사용합니다.

사용자가 프로그램 최초 설정 시 입력할 수 있도록 합니다.

한 번 설정하면 이후 프로그램 실행 때마다 다시 입력할 필요가 없도록 PC에 저장합니다.

API Key나 Token을 소스코드에 hard-code하지 않습니다.

설정 화면에서 다음 항목을 변경할 수 있도록 합니다.

- OpenAI API Key
- 사용할 GPT 모델명
- Notion Integration Token
- Notion 영어듣기 Page ID


[11. GUI]

일반적인 Windows 데스크톱 프로그램 형태로 만들어 주세요.

복잡한 개발자용 인터페이스가 아니라 개인이 반복적으로 사용하기 편한 단순한 GUI를 목표로 합니다.

메인 화면에는 최소한 다음 기능을 제공합니다.

입력 방식:
- 영상 파일 선택
- YouTube URL 입력

실행:
- 전사 및 저장 시작

진행 상태:
- 영상 준비
- 오디오 추출
- Whisper 전사
- GPT 번역
- 전사문 구성
- Notion 업로드
- 완료

현재 어느 단계인지 명확하게 표시해 주세요.

가능하다면 각 단계의 진행률도 표시합니다.

설정:
- OpenAI API 설정
- GPT 모델
- Notion Token
- Notion Page ID

작업 중 UI가 멈추지 않도록 긴 작업은 background worker/thread/process 등 적절한 방식으로 처리합니다.


[12. 오류 처리]

다음 상황을 사용자에게 명확하게 알려 주세요.

- CUDA/GPU 사용 불가
- Whisper 모델 로딩 실패
- 영상 파일 읽기 실패
- YouTube 다운로드 실패
- OpenAI API 인증 실패
- OpenAI API 사용량/결제 문제
- GPT 번역 실패
- GPT 번역 결과 구조 불일치
- 인터넷 연결 문제
- Notion 인증 실패
- Notion 페이지 접근 권한 없음
- Notion 저장 실패

가능하면 전체 파이프라인을 처음부터 다시 실행하지 않고 실패한 단계부터 재시도할 수 있도록 설계합니다.


[13. 개발 방식]

먼저 바로 코딩을 시작하지 말고 다음 순서로 진행해 주세요.

1. 요구사항 분석
2. 전체 architecture 설계
3. 사용할 라이브러리와 기술 선정
4. 데이터가 각 단계에서 어떤 형태로 전달되는지 정의
5. Whisper segment → GPT translation → timestamp → Notion block으로 이어지는 데이터 구조 설계
6. 오류 및 재시도 전략 설계
7. 구현
8. 테스트
9. Windows .exe 패키징

특정 라이브러리를 제가 요구한 경우를 제외하면, 현재 유지보수가 잘 되고 Windows 환경에서 안정적으로 동작하는 라이브러리를 선택해 주세요.

불필요하게 복잡한 framework나 서버는 사용하지 마세요.

이 프로그램에는 별도의 웹 서버나 클라우드 서버가 필요하지 않습니다.

Whisper 전사는 사용자 PC에서 로컬로 수행하고, 인터넷 연결이 필요한 부분은 OpenAI API, Notion API, YouTube 입력을 사용하는 경우뿐입니다.


[14. 최종 테스트]

완성 전에 최소한 다음을 검증해 주세요.

- MP4 입력 → 전체 과정 정상 완료
- MKV/MOV/WEBM 입력
- YouTube URL 입력
- RTX 4060 CUDA 가속이 실제로 사용되는지
- large-v3-turbo가 정상적으로 로딩되는지
- 영어 전사 원문이 GPT 단계에서 변경되지 않는지
- 영어 문장과 한국어 번역이 1:1로 대응되는지
- 2분 단위 타임스탬프가 올바른 위치에 들어가는지
- 긴 영상에서도 번역 문장 누락/순서 변경이 없는지
- Notion "영어듣기" 아래에 올바른 제목으로 하위 페이지가 생성되는지
- 긴 전사문 전체가 Notion에 빠짐없이 저장되는지
- 작업 완료 후 임시 파일이 정리되는지
- 오류가 발생했을 때 프로그램 전체가 비정상 종료되지 않는지


[최종 목표]

사용자 입장에서는 최종적으로 다음 정도의 과정만 필요해야 합니다.

프로그램 실행
→ 영상 파일 선택 또는 YouTube URL 붙여넣기
→ 시작 버튼 클릭
→ 기다림
→ Notion의 "영어듣기" 페이지 아래에 완성된 영어/한국어 전사문 페이지가 자동 생성

프로그램 완성 후에는 Kiro를 실행하지 않아도 독립적으로 사용할 수 있는 Windows .exe 형태로 패키징해 주세요.
